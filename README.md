# GymSystem
Proyecto final de Desarrollo de Aplicaciones Web y Patrones
Grupo #7
GymSystem

El proyecto GymSystem es una aplicación web multiempresa para la gestión integral de gimnasios, que unifica en una sola plataforma la administración, el acompañamiento al cliente y la actividad comercial para facilitar el manejo de un sistema de gimnasio para un potencial cliente, al ser multiempresa conserva la característica de poder personalizarse posteriormente para cada cliente.
